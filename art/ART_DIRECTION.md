## 一、整体氛围基调

**一句话：暗黑水墨绘本 × 梦境哥特 —— 「腐朽的优雅」。**

《溯梦》讲的是一个人向梦境深处下潜三十层的故事。视觉要同时传达两种感受：

- **梦的瑰丽** —— 紫黑色的夜空、星云、金色符线、琉璃与烛火，让玩家留恋这个梦；
- **梦的腐败** —— 墨汁般化开的形体、空洞的眼眶、被蛀蚀的华丽，提醒玩家这个梦在吃人。

基调关键词：`幽暗` `华丽` `水墨晕染` `星河` `哑金` `腐败感` `绘本叙事`

气质参照（仅作方向锚点，不模仿具体作品）：空洞骑士的孤独感 × 渎神的宗教式腐败 × 中式水墨的留白与晕染。

### 色彩规范

| 角色 | 颜色 | 用途 |
|---|---|---|
| 主底色 | 深紫黑 `#0d0819` ~ `#1a1030` | 背景、夜空、墨影 |
| 点缀色 | 哑金 / 旧金 `#c9a86a` | 符线、纹饰、光晕、眼眶 |
| 高光色 | 青白 / 月白 `#dfe8ff` | 月光、魂魄、琉璃反光 |
| 警示色 | 暗玫红 `#9d2b4e` | 仅用于战斗 UI 与伤害，不进立绘 |

**禁止出现**：高饱和荧光色、现代物品、写实照片质感、日漫画风、明亮暖色调场景。

## 二、制作规范（AI 出图流程）

### 提示词模板（英文正向）

```
Dark ink-wash storybook illustration of <主体描述>, deep purple and black
palette with muted gold accents, smooth clean dark misty background,
elegant composition, <构图要求>. No text, no watermark, no signature,
no glitch artifacts, clean edges.
```

要点：

- 主体描述必须具体（形态、材质、动作、标志性细节各给一个）；
- 「deep purple and black palette with muted gold accents」是全套图的统一锚点，不可删；
- 负面约束固定为 `No text, no watermark, no signature, no glitch artifacts, clean edges` —— 生成模型爱在角落加中文字条幅、红色印章和 RGB 故障噪点，这句话能显著降低概率但不能根除。

### 尺寸规范

| 类型 | 尺寸 | 说明 |
|---|---|---|
| Boss 立绘 | 1024×1536（竖版） | 战斗面板展示高度 max-h-80 |
| 小怪立绘 | 1024×1024（方图） | 战斗面板展示高度 max-h-64 |
| 横版主视觉 | 1536×1024 或 2048×1152 | 标题页/结局用（规划中） |

### 质检清单（每张必过）

1. 裁掉底部约 5.5%（生成图左下角固定有「AI生成」水印）；
2. 全图检查 RGB 故障噪点、中文字条幅、红色印章 —— 少量边缘噪点可用中值滤波程序清理（脚本见本节末尾），**成簇的大片噪点不要硬修，直接重新生成**；
3. 用 ReadMediaFile 目检一遍再入库；
4. 原图存 `art/`，同步复制到 `public/art/`，代码中以 `/art/<文件名>` 引用。

### 命名规范

`boss-<id>.png` / `mob-<id>.png` / `scene-<事件id>.png` / `relic-<id>.png` / `ui-<用途>.png`，id 与 `src/game/data.ts` 中的数据 id 保持一致。

## 四、后续扩充路线（按优先级分阶段）

### P0 · 标题页主视觉（1 张）✅ 已完成并接入

### P1 · 结局与过场插画（3~4 张）✅ 已完成并接入

### P2 · 事件场景插图（先做 6~10 张高频/标志性事件）

现有 57 个事件目前纯文字。不建议全配，优先给**出现频率高、画面感强**的事件配 1536×1024 横版小插图，显示在事件标题下方。候选方向：

- 商人/商店类（提灯商人的摊位）；
- 休息/泉水类（月光下的梦境泉眼）；
- 宝箱/奇遇类（悬浮的琉璃匣）；
- 诅咒/陷阱类（墨手从地面伸出）；
- 每层过渡场景（梦境阶梯向下盘旋）。

风格上场景图要比立绘更「空」：大面积留白和晕染，主体占比小，营造纵深。

### P3 · 遗物图标与 UI 装饰

- **遗物图标 ×13**（月光碎片、荆棘之冠、梦貘之角、沉眠之羽、镜面具、血契匕首、不灭烛火、星尘瓶、饕餮钱袋、清醒之戒、呢喃之匣、碎梦王冠、梦主之瞳）：512×512 方图、去背 PNG（transparent），替换现有 emoji。诅咒类遗物（呢喃之匣、碎梦王冠）统一加暗玫红描边以作区分；
- **UI 装饰**（可选）：面板边角的水墨纹、按钮 hover 的金线流光、图鉴的书页底纹。这类建议最后用 CSS/SVG 实现，不占出图额度。

### 不推荐做的

- 每层 30 张独立场景背景 —— 量大且会喧宾夺主，用文字+渐变即可；
- 旅人主角立绘 —— 主角保持「无面」更能让玩家代入，最多给一个提灯剪影（见 P0）。

## 五、维护约定

1. 任何新图先按第二节模板出提示词，重大风格偏离需先改本文档再出图；
2. 外包精修时，把本文档 + 对应立绘 PNG 一起发给画师，作为风格参照；
3. 每次新增资产后更新第三节清单表；
4. 历史版本（被替换的 v1 图）不保留在仓库内，避免体积膨胀。
